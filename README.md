# 📊 Raw2Insight — Data Visualization

> Turning 10,000 rows of café sales data into clear and meaningful visual insights using Python, Pandas, and Matplotlib.

## 🚀 About the Project

Raw2Insight — Data Visualization is a practical data visualization project built on a cleaned café sales dataset containing **10,000 transaction records**.

The goal of this project is to transform raw numerical and categorical data into **clear, professional, and easy-to-understand visual insights**.

Instead of looking at thousands of individual rows, the data is presented through different charts, with each visualization selected according to the question it helps answer.

## 📈 Visualizations

| Chart | Purpose |
|---|---|
| 📈 Line Chart | Analyze monthly sales revenue throughout 2023 |
| 📊 Bar Chart | Compare total sales generated by each product |
| 🥧 Pie Chart | Understand the distribution of payment methods |
| 📉 Histogram | Analyze the distribution of transaction spending |
| 🔵 Scatter Plot | Explore the relationship between quantity and transaction value |

## 🛠️ Technologies Used

- 🐍 Python
- 🐼 Pandas
- 📊 Matplotlib
